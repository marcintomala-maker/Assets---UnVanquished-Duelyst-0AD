# 🎨 Free Game Art Finder: 0 A.D. + Unvanquished

A simple web page for browsing **19,533** pictures, sounds, music tracks and 3D models from the free games **0 A.D.** and **Unvanquished**. Every item is marked with whether you can use it.

**Open it:** https://marcintomala-maker.github.io/Assets---UnVanquished-Duelyst-0AD/

Or download `index.html`, `app.js` and `catalog.js` into one folder and double-click `index.html`.

## How to use

1. Pick a game and what you want (pictures, sounds, 3D models…).
2. Type a word in the search box, like `horse` or `door`.
3. Tick **"Hide things I can't use"** to hide everything red or orange.
4. Click an item to see it big, hear it, or turn it in 3D.
5. Press **"Copy credit text"** and paste it into your game's credits file.

## Colors

- ✅ green: free, or free with credit
- 🟡 yellow: free with credit; if you change the file, share the changed file
- ⛔ red: can't sell (free projects only)
- ❓ orange: not sure, so ask first

## What's in this repo

| File | What it is |
|---|---|
| `index.html`, `app.js` | the app |
| `catalog.js` | the list of all files + licenses the app reads |
| `assets-and-licenses.csv` | the same list as a spreadsheet |
| `LICENSES.md` | how each license was checked, and every problem file |

No game files are stored here. Previews load straight from the games' public code pages.
